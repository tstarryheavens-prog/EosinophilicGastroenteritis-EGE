1. 実現した機能と、使ってみて実感した嬉しさ

どうも、ぽトル（Pottle）です。

生成AIに文章やブログ記事の下書きを書かせたとき、次のような言い回しに違和感を覚えた経験はありませんか？

  • 「現場の手触り感を大切にしながら、課題の解像度を上げていく」
  • 「この意思決定OSによって、システムが静かに壊れるのを防ぐ」
  • 「泥臭い試行錯誤の末に、時間を溶かして手に入れた知見」

こうした言葉は、一見それらしく見えますが、普段の会話や文章ではまず使いません。
さらに、無駄な太字が散りばめられ、語尾に「〜のではないでしょうか？」と定型文が並ぶと、読者は一目で「あ、これはAIが適当に吐き出した文章だな」と冷めてしまいます。

これらを一括で修正するために構築したのが、日本語推敲プロトコル「yomiyasu（読みやす）」です。

🎉 導入して何が嬉しかったか？
  • 書き直しの手作業が激減した：AI特有の誇張表現を人間がいちいち手で削る苦行から解放されました。
  • 自分のキャラクター口調が崩れない：ぽトルの「だらだら暮らすパンダ口調」を保ったまま、構文のねじれや不自然な単語だけを綺麗に取り除けます。
  • 読者の離脱を防げる：平均文長が30〜45文字のリズムに整うため、すっと頭に入り最後まで読まれる記事になります。
  • 自動Lint検査で安心できる：執筆後に専用のPythonスクリプトを実行するだけで、AIっぽい比喩の残りを客観的にチェックできます。

2. yomiyasuが定める7つの推敲原則

yomiyasuでは、文章の意味や主張を変えずに、表現だけを日常の自然な言葉に整えるルールを定めています。

1. 意味と比重の保持
元の文章が伝えている事実や主張の強さを変えず、勝手な情報を足しません。
2. AI特有の疑似具体語の排除
「手触り」「解像度」「泥臭い」などの比喩を、具体的で平易な言葉に改めます。
3. 比喩動詞の平文化
「時間を溶かす」「静かに壊れる」を「時間を費やす」「気づかないうちに止まる」にします。
4. 擬人化の解消
「コードが語る」「システムが願う」など、非生物に感情や意志を持たせません。
5. 不要な否定対比の整理
「AではなくB」のような過度な対比を減らし、自然な肯定文で述べるようにします。
6. 装飾と太字の適正化
1段落すべてを太字にしたり、記号を乱用せず、本当に伝えたい部分だけを強調します。

3. ステップバイステップ導入手順

ステップ1: プロンプトにyomiyasuの推敲指示を組み込む

AIに文章を書かせる際、プロンプトの最後に以下のルールを追加します。これだけで出力の質が大きく変わります。 

【推敲ルール（yomiyasu原則）】
1. 「手触り」「解像度」「泥臭い」「時間を溶かす」「意思決定OS」などの不自然な比喩を一切使わないこと。
2. 道具やシステムに意志を持たせる擬人化（「システムが願う」など）をしないこと。
3. 過度な太字強調や箇条書きの連発を避け、平均文長30〜45文字のリズムで書くこと。
4. 指定されたキャラクターの口調・トーンは最優先で維持すること。

ステップ2: 自動Lintスクリプトで文章を機械検査する

人の目視チェックだけでは見落としがちなAI頻出語を、Pythonスクリプトで検知します。Python標準ライブラリのみで動作するため、追加パッケージのインストールは不要です。

実行環境の準備と動作確認：

# Python 3.8以上があれば外部ライブラリのインストール不要で即座に動作します
python3 -V

# スクリプトを実行してMarkdown原稿を検査
python3 yomiyasu_lint.py article_draft.md

完全なスクリプトコード（yomiyasu_lint.py）：

#!/usr/bin/env python3
"""
yomiyasu_lint.py - 日本語の表現とMarkdownの書式を、設定されたルールで点検する。
Python標準ライブラリだけで動作します。
"""

import sys
import re
import argparse
from typing import List, Tuple

# AI特有の頻出語（手触り、解像度、泥臭い、意思決定OSなど）
SLOP_WORDS = [
    "手触り", "肌感", "肌感覚", "体温", "温度感", "熱量", "血の通った", "泥臭い", "泥臭さ",
    "解像度", "腹落ち", "メンタルモデル", "本質的", "地に足のついた", "等身大",
    "営み", "装置", "意思決定OS", "土台", "羅針盤", "起爆剤", "触媒",
    "真理", "虚飾", "境地", "美学", "深淵", "冷徹", "禁欲的", "優美", "極致", "宿命", "正本"
]

METAPHOR_VERB_PATTERNS = [
    (r"(地味に|よく|じわじわ)効[かきくけいた]", "比喩動詞「効く」の過剰使用"),
    (r"(データ|仕様|設計|環境|ビルド|システム|秩序)が(静かに)?壊れ", "比喩動詞「壊れる」"),
    (r"静かに(壊れ|落ち|失敗|沈黙)", "直訳「静かに壊れる (silently fail)」"),
    (r"黙って(無視|捨て|スキップ|破棄)", "直訳「黙って無視される」"),
    (r"側に倒[すしせ]", "判断を方向で表現する「〜側に倒す」"),
    (r"時間[をに]溶か[したす]", "比喩動詞「時間を溶かす」"),
    (r"(1つずつ|一つずつ)潰[していく]", "比喩動詞「潰す」"),
    (r"(実装|詳細|コード|設計|内部|仕組み|領域|本質)(に|まで|へ)踏み込[んむみま]", "比喩動詞「踏み込む」"),
    (r"動かしながら引き返[すし]", "比喩動詞「引き返す」"),
]

FILLER_PATTERNS = [
    (r"^(まず|ここで)?重要なのは、?", "前置フィラー「重要なのは」"),
    (r"^結論から言うと、?", "前置フィラー「結論から言うと」"),
    (r"^正直に言うと、?", "前置フィラー「正直に言うと」"),
    (r"いかがでした(でしょうか|か)?[？?。]?$", "定型クロージング「いかがでしたでしょうか」"),
    (r"ぜひ(参考|試し|活用)(に)?して(みて)?ください[！!。]?", "定型クロージング「ぜひ〜してみてください」"),
]

def check_file(path: str):
    with open(path, "r", encoding="utf-8") as f:
        lines = f.readlines()

    issues = []
    bold_count = 0
    total_sentences = 0

    for idx, line in enumerate(lines, 1):
        bold_count += len(re.findall(r"\*\*[^*]+\*\*", line))
        
        # スロップ単語チェック
        for word in SLOP_WORDS:
            if word in line:
                issues.append((idx, f"AI頻出語の検出: 「{word}」"))

        # 比喩動詞チェック
        for pat, desc in METAPHOR_VERB_PATTERNS:
            if re.search(pat, line):
                issues.append((idx, f"{desc}"))

        # フィラーチェック
        for pat, desc in FILLER_PATTERNS:
            if re.search(pat, line.strip()):
                issues.append((idx, f"{desc}"))

    print(f"=== yomiyasu 検査レポート: {path} ===")
    print(f"総行数: {len(lines)}行 | 太字強調: {bold_count}箇所")
    if not issues:
        print("✅ 問題のあるAI頻出表現は見つかりませんでした。素直で読みやすい文章です！")
    else:
        print(f"⚠️  {len(issues)} 件の確認候補が見つかりました:")
        for line_no, msg in issues:
            print(f"  行 {line_no:3d}: {msg}")

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("使用法: python3 yomiyasu_lint.py ")
        sys.exit(1)
    check_file(sys.argv[1])

実行すると、太字の出現頻度、箇条書き比率、検出された比喩動詞の行番号と改善提案が一覧表示されます。

MacでOneDriveを使っている方なら、一度はこの罠に引っかかったことがあるはずです。
「MacのOneDrive同期フォルダの中をAIに探させても、『中身が空です』と言われるか、ファイルが見つからない」という問題です。

原因はMacの「ファイル・オンデマンド（Files-On-Demand）」機能。MacのSSD容量を食わないように、未ダウンロードのファイルは「0バイトのプレースホルダー」として扱われるため、ローカルのツールやAIからは中身が一切読めないのです。

さらに、OneNoteのメモやノートブックもMacアプリからはデータを取り出すAPIがありません。
この「MacとMicrosoft 365の断絶」を一発で解決したのが、Microsoft Graph API直結のMCPサーバー「ms-365」です！

1. ms-365 の導入と「プリセット厳選」の重要性

公式・コミュニティで実績のある@softeria/ms-365-mcp-serverを使用します。
ここで最大のポイントは、全ツールを有効化しないことです。デフォルトだとTeamsやOutlookメールなど300個以上のツールが登録され、AIの入力メモリ（トークン）がパンクしてしまいます。

そこで、--preset files,onenote を指定して、ファイル検索とOneNoteメモの34ツールだけに絞り込みます。

⚙️ 設定ファイル（~/.gemini/config/mcp_config.json）
"ms-365": {
  "command": "/opt/homebrew/bin/npx",
  "args": [
    "-y",
    "@softeria/ms-365-mcp-server",
    "--preset",
    "files,onenote"
  ],
  "env": {
    "MS365_MCP_CLIENT_ID": "your-azure-app-client-id",
    "MS365_MCP_TENANT_ID": "consumers"
  }
}

※初回起動時にコンソールまたはブラウザでMicrosoft個人アカウント（`consumers`）のOAuth認証を行えば、トークンはOSのキーチェーンに安全に保存されます。

2. 世間一般のビジネス活用事例

🏢 業務での代表的なユースケース

  • 巨大OneDrive内の契約書・企画書の全文横断検索： ファイル名が「無題」や日付だけでも、本文のテキストをクラウドインデックスで即座に発見。
  • OneNote議事録からのタスク自動抽出： 過去の会議メモ全セクションをAIに走査させ、「未完了のアクションアイテム一覧」を一撃作成。
  • 共同編集資料の差分要約： チームメンバーが編集したOneDrive上の最新ドキュメントの変更箇所をチャットで要約。

3. 🐼 我が家のリアル活用事例：10年前のトヨタホーム建築・融資書類の瞬時サルベージ

我が家では、2016年に新築したトヨタホームの「土地・建物総額5,200万円の過去書類（見積書、527万円の値引き内訳書、三井住友信託のつなぎ融資計算書、太陽光・蓄電池の保証書）」のサルベージに大活躍しています。

🔥 実際にAIに投げた指示：

「OneDriveの中から、2015〜2016年のトヨタホームの見積書と値引き内訳を探して。本体値引きとキャンペーン値引きがそれぞれいくらだったか、正確な数字を抽出して表にして！」

Mac本体にはダウンロードされていない古いPDFファイルでしたが、AIがsearch-onedrive-filesツールでクラウド上のインデックスを直接叩き、該当ファイルを特定。内容を直接読み込んで「建物本体値引き：〇〇万円、モニター協力値引き：〇〇万円、合計：527万円」と一瞬で正確な表を作ってくれました。
おかげで、はてなブログ連載の検証記事の信頼性を100%裏付けることができました！

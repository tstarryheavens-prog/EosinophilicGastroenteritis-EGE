① excel-live：起動中のExcelをリアルタイム操作（Apple Events連動）
② ms-365：OneDrive・OneNoteのクラウドデータ直結
③ yomitoku：日本語特化・超高精度OCR＆表抽出エンジン
④ laya：単一パス（約33ms）の超高速・確信度付き構造化判定
⑤ paper2agent：論文・GitHubリポジトリの即時MCPエージェント化
⑥ gemini-notebook-mcp：NotebookLMノートブックの横断検索・リサーチ

それぞれの「概要」「導入設定（mcp_config.json）」「世間一般的な活用例」、そして何より「我が家でのリアルな実践事例」を包み隠さずご紹介します！

MCP 01 macOS Excel ライブ連動

📊 excel-live（macOS-excel-mcp）

一般的な「裏でxlsxファイルを書き出して保存する」スクリプトとは異なり、Mac上で開いているExcelウィンドウをApple Events経由で直接操作します。セルへの値書き込み、SUM/VLOOKUP関数の埋め込み、罫線・背景色フォーマット、選択範囲の瞬時読み取りがリアルタイムに画面上で行われます。

⚙️ 設定例（mcp_config.json）
"excel-live": {
  "command": "/path/to/venv/bin/python",
  "args": ["/path/to/macos-excel-mcp/server.py"]
}
🏢 一般的な活用事例

売上報告書の月次自動集計、散らかったCSVの自動フォーマット整形、関数とカラーリングを施したダッシュボードの瞬時作成。

🐼 我が家のリアル活用事例：1,413行のウルトラマンCGカード照合

子供と集めているウルトラマンカードの管理台帳（Excel・1,413行）を開いたまま、AIが公式APIの最新1,339枚とリアルタイム照合。「未保有カード」「第3弾のレアカード」を自動ハイライト＆数式挿入し、重複購入を完全撲滅！

MCP 02 クラウドストレージ＆ノート直結

☁️ ms-365（OneDrive & OneNote）

Macのオンデマンド同期（Files-On-Demand）により、未ダウンロードファイルがローカルから見えず0バイト扱いになる問題をMicrosoft Graph API経由で完全突破。300以上のツールから--preset files,onenoteで34個に厳選し、超低レイテンシでクラウド全文検索・OneNote全ページ抽出を実現します。

⚙️ 設定例（mcp_config.json）
"ms-365": {
  "command": "npx",
  "args": ["-y", "@softeria/ms-365-mcp-server", "--preset", "files,onenote"],
  "env": {
    "MS365_MCP_CLIENT_ID": "your-client-id",
    "MS365_MCP_TENANT_ID": "consumers"
  }
}
🏢 一般的な活用事例

散らかったOneDrive内の提案書・契約書の一括横断検索、OneNote議事録からのタスク自動抽出、社内ナレッジの即時要約。

🐼 我が家のリアル活用事例：10年分のトヨタホーム新築・融資書類の瞬時サルベージ

OneDriveに眠る10年前の建築見積書、527万円の値引き内訳書、三井住友信託のつなぎ融資明細をクラウド検索。Macに同期していない重いPDFも即座にAIが内容を把握し、ブログ連載記事の検証データを裏付け！

MCP 03 日本語高精度Document AI

📑 yomitoku（日本語特化OCR＆表抽出）

日本国内の研究チームが開発した日本語特化のOCRエンジン「YomiToku」をローカルMCPサーバー化。傾いた領収書や複雑にセル結合されたPDF表であっても、段落構造を崩さず正確なCSVやMarkdown表に復元します。

⚙️ 設定例（mcp_config.json）
"yomitoku": {
  "command": "/path/to/venv/bin/python",
  "args": ["/path/to/yomitoku-mcp/server.py"]
}
🏢 一般的な活用事例

紙の確定申告書類・領収書のデータ化、手書き混じりのアンケートや業務日報のCSV変換、紙カタログのスペック表抽出。

🐼 我が家のリアル活用事例：難病の血液検査データ＆処方薬明細の完全表化

好酸球性胃腸炎・群発頭痛で通院した際の「血液検査結果用紙（好酸球比率・CRPなど）」や「薬局の調剤明細」をスマホ写真でパシャリ。yomitokuが結合セルを完全に保ったままCSV化し、医療データベースへ全自動登録！

MCP 04 約33ms 単一パス推論意思決定

⚡ laya（超高速・確信度付き構造化判定）

一般的なLLMの「トークンを1文字ずつ出力して待たされる」方式ではなく、Metal GPU上の単一フォワードパス（約33ms）で動作する非自己回帰型エンジン。100+言語対応で、判定結果に校正済み確信度（Confidence / Probability）が付与されるため、「確信度90%以上なら即時自動実行、未満なら人間に確認」という堅牢なゲート制御が可能です。

⚙️ 設定例（mcp_config.json）
"laya": {
  "command": "/path/to/laya-mcp/.venv/bin/laya-mcp-server"
}
🏢 一般的な活用事例

カスタマーサポートの問い合わせ自動ルーティング、サーバーエラーログの障害深刻度判定（P0〜P3トリアージ）、スパム判定。

🐼 我が家のリアル活用事例：ECHONET Lite蓄電池エラーの0.03秒トリアージ

深夜の自作HEMSで蓄電池とのUDP通信が途切れた際、膨大な生パケットから「単なる一時タイムアウトか、機器異常か」をlayaが0.03秒で判定。95%以上の確率で単なるソケット滞留と分かれば自動再接続し、寝ている私を起こさず自己修復！

MCP 05 学術論文・GitHubのリバースMCP化

🔬 paper2agent（論文・コードの即時エージェント化）

スタンフォード大学等の最新研究（Nature 2026）に基づくフレームワーク。arXivやバイオインフォマティクスの論文PDF、またはGitHubリポジトリを渡すと、論文内で提案されているアルゴリズムを解析し、動作するMCPサーバーのコードを自動生成・検証してくれます。

⚙️ 設定例（mcp_config.json）
"paper2agent": {
  "command": "/path/to/Paper2Agent/.venv/bin/python",
  "args": ["/path/to/Paper2Agent/server.py"]
}
🏢 一般的な活用事例

最新の機械学習・バイオ論文の検証追試、未パッケージ化のリポジトリをチームのAIエージェントから即使えるツールへと昇格。

🐼 我が家のリアル活用事例：難病・好酸球性疾患の最新抗体薬論文の解析ツール化

好酸球性胃腸炎やCGRP関連（群発頭痛）の海外最新論文PDFから、治験データや作用機序の解析関数をMCPサーバーとして抽出。医師との面談前に最新エビデンスを体系化して備える武器に！

MCP 06 Googleリサーチ基盤直結

📓 gemini-notebook-mcp（NotebookLM連携）

GoogleのAIノート「NotebookLM」のコレクションやノートブックをMCP経由で直接操作。アップロード済みの膨大な参考資料（PDF、Web記事、Google Driveファイル）を、AntigravityやClaudeのチャット内から直接クエリ＆クロスノート横断検索できます。

⚙️ 設定例（mcp_config.json）
"gemini-notebook-mcp": {
  "command": "/path/to/notebooklm-mcp",
  "args": [],
  "env": {
    "NOTEBOOKLM_HL": "ja"
  }
}
🏢 一般的な活用事例

大量の業界レポート・マニュアルを投入した特化型FAQボット、ポッドキャスト風オーディオ要約の自動生成、学術リサーチの整理。

🐼 我が家のリアル活用事例：愛知県高校入試の出題傾向＆内申点ルール横断検索

愛知県教育委員会が発表している公立高校入試の過去問解説、推薦基準、学校群ごとの当日点換算（Ⅰ型〜Ⅴ型）の全PDFをNotebookLMへ格納。AIが質問に応じて瞬時に正確な出題傾向と受験戦略を回答！

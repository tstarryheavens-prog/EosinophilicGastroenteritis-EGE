海外製のOCRモデルは欧米のシンプルな表には強いのですが、日本の役所や病院、会計ソフトが吐き出す「複雑怪奇なセル結合の帳票」にはめっぽう弱いのが現実です。

この問題を根本から解決したのが、日本の研究チームが開発した日本語特化のDocument AIエンジン「YomiToku（読み解く）」を組み込んだMCPサーバーです！

1. yomitoku MCP の凄さと導入手順

YomiTokuは、文字の認識だけでなく「レイアウト解析（見出し、段落、表のセル境界）」を同時に行います。そのため、スマホで斜めに撮った紙の書類であっても、行と列を正しく認識して綺麗なCSVやMarkdownテーブルとして出力できます。

🛠️ 提供されるMCPツール：

  • ocr_document：画像やPDFから文字を抽出し、Markdown/HTML/JSON形式で出力
  • extract_tables：帳票から「表（テーブル）」だけを特定し、結合セルを保ったまま完全なCSV文字列として抽出
⚙️ 設定ファイル（~/.gemini/config/mcp_config.json）
"yomitoku": {
  "command": "/Users//my-mcp-server/yomitoku-mcp/.venv/bin/python",
  "args": [
    "/Users//my-mcp-server/yomitoku-mcp/server.py"
  ]
}

2. 世間一般のビジネス・生活活用事例

🏢 業務での代表的なユースケース

  • 確定申告・医療費控除の領収書データ化： 束になった領収書をスマホで撮るだけで、日付・店名・金額・税率を正確にCSV化。
  • 紙の社内帳票や仕様書のデジタル化： 過去の紙カタログやスペック比較表を一瞬で再編集可能なスプレッドシートデータに変換。
  • アンケート集計： 手書き混じりの紙のアンケート用紙から回答欄を自動抽出。

3. 🐼 我が家のリアル活用事例：難病の血液検査結果用紙＆調剤明細の完全データ化

私自身、好酸球性胃腸炎・群発頭痛・重症喘息という複数の難病・慢性疾患と向き合っています。
定期通院のたびに渡されるのが、「好酸球比率や炎症マーカー（CRP）がビッシリ書かれた血液検査結果用紙」と「薬局の調剤明細書」です。

🔥 実際にAIに投げた指示：

「この血液検査結果の写真を yomitoku で解析して、検査項目名、数値、基準値、単位をすべて抽出してCSVにして。そのまま医療記録データベースに追加して！」

一般的なAIだと「WBC」と「白血球数」の行がズレたり、好酸球の「%」が数値とくっついたりしがちですが、yomitokuは一発で寸分の狂いもない完全な表として出力してくれました。
これを自作の闘病ポータル（好酸球性疾患アーカイブ）の時系列グラフに自動投入。主治医との診察時にも「過去半年の好酸球推移グラフ」をiPadで見せられるようになり、診察の質が格段に上がりました！

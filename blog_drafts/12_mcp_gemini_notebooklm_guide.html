1. gemini-notebook-mcp の仕組みと導入手順

このMCPサーバーは、ブラウザ上のNotebookLMセッションと連携し、登録されているノートブック一覧の取得、資料の追加、そして複数ノートブックにまたがる横断クエリ（クロスノート検索）をMCPツールとして提供します。

🛠️ 使える主なMCPツール群：

  • notebook_list：作成済みのノートブック一覧を取得
  • notebook_query：指定したノートブックに対してプロンプトを投げて資料準拠の回答を取得
  • cross_notebook_query：複数のノートブックを跨いで一括検索・比較
  • source_add：WebのURLやテキストを直接ノートブックのソースに追加
⚙️ 設定ファイル（~/.gemini/config/mcp_config.json）
"gemini-notebook-mcp": {
  "command": "/Users//.local/bin/notebooklm-mcp",
  "args": [],
  "env": {
    "NOTEBOOKLM_HL": "ja"
  }
}

3. 🐼 我が家のリアル活用事例：愛知県公立高校入試の配点比率・過去問出題傾向の横断分析！

我が家では、子供の中学進学・高校受験に向けて「愛知県公立高校入試（尾張・名古屋地区）」の全入試要項・過去問データをNotebookLMに集約しています。

🔥 実際にAIに投げた指示：

「NotebookLMの『愛知県高校入試』ノートを検索して。尾張第1群・Aグループの進学校で、当日点重視（Ⅲ型：当日点×1.5）と均等（Ⅰ型）の高校をリストアップし、過去3年の数学の頻出単元を教えて！」

AIはnotebook_queryを使って、愛知県教育委員会が発表した複雑な学校群配点表と過去問分析PDFを一瞬で横断検索。
「〇〇高校は当日点重視のⅢ型なので内申点が36でも当日点で逆転可能」「図形と関数の融合問題が毎年大問3で出題」といった極めて具体的でハルシネーションのない確実なアドバイスがチャット上で即座に返ってきました。
これを自作ポータル（愛知県公立高校進学ガイド）のコンテンツ強化にも活用しています！

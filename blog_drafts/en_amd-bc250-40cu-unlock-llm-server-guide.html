The Pitfalls & Failure Modes We Overcame

  • Ubuntu 24.04 RANDSTRUCT Rejection: Building a patched amdgpu on Ubuntu failed with Exec format error due to kernel struct randomization. Solved by moving to Fedora 45 Server.
  • ACPI Warm Reboot Lockup: The mining firmware fails to re-enumerate reset signals, causing black-screen hangs on reboot. Solved with GRUB parameter reboot=acpi,cold.
  • LVM 15GB Disk Ceiling: Fedora Server defaults to a 15GB root logical volume regardless of NVMe drive size. Solved with sudo lvextend -l +100%FREE /dev/mapper/fedora-root -r.
  • Unpatched Initramfs Persistence: Installing patched kernel modules did not take effect because Fedora booted the stock module bundled inside the initramfs. Solved via sudo dracut --regenerate-all --force and amdgpu.bc250_cc_write_mode=3.
  • SELinux status=203/EXEC: Running llama-server from user home directories under systemd triggered SELinux execution denials. Solved by deploying to /usr/local/bin with proper restorecon labeling.

End-to-End Build Walkthrough (Fedora 45 Server)

BASH 
# 1. Expand LVM disk space to 100% of NVMe
sudo lvextend -l +100%FREE /dev/mapper/fedora-root -r

# 2. Add reboot hang fix and 14GB VRAM/GTT reservation to GRUB
sudo grubby --update-kernel=ALL --args="reboot=acpi,cold amdgpu.gttsize=14336 ttm.pages_limit=3670016"

# 3. Setup Tailscale & Firewall
sudo dnf config-manager addrepo --from-repofile=https://pkgs.tailscale.com/stable/fedora/tailscale.repo
sudo dnf install -y tailscale && sudo systemctl enable --now tailscaled
sudo tailscale up --ssh --accept-routes
sudo firewall-cmd --permanent --zone=trusted --add-interface=tailscale0
sudo firewall-cmd --permanent --add-port=8080/tcp && sudo firewall-cmd --reload

# 4. Patch amdgpu for Full 40 CU unlock
sudo dnf --enablerepo=updates-testing install -y kernel-devel-$(uname -r) kernel-headers gcc make zstd curl
git clone https://github.com/duggasco/bc250-40cu-unlock.git ~/bc250-40cu-unlock
cd ~/bc250-40cu-unlock && sudo ./scripts/bc250-enable-40cu-fedora.sh build
sudo grubby --update-kernel=ALL --args="amdgpu.bc250_cc_write_mode=3"
sudo dracut --regenerate-all --force && sudo systemctl reboot

Unlocking 8 Cores / 16 Threads & Running Phi-4 14B

BASH 
# 1. Flip SMU Register 0x0115A870 from 0x77 to 0xFF (Unmask Cores 3 & 7)
git clone https://github.com/GabriWar/bc250-core-cu-unlock.git ~/bc250-core-cu-unlock
cd ~/bc250-core-cu-unlock
sudo ./bc250-8core-unlock.sh install
sudo ./bc250-8core-unlock.sh apply --reboot
# Verify: nproc -> 16

# 2. Build llama.cpp with Mesa RADV Vulkan Backend (16-thread compilation)
sudo dnf install -y cmake gcc-c++ vulkan-loader-devel mesa-vulkan-drivers vulkan-tools glslc spirv-headers-devel spirv-tools-devel
git clone https://github.com/ggerganov/llama.cpp.git ~/llama.cpp
cd ~/llama.cpp && cmake -B build -DGGML_VULKAN=ON && cmake --build build --config Release -j16
sudo cp build/bin/llama-server /usr/local/bin/ && sudo restorecon -v /usr/local/bin/llama-server

# 3. Deploy Microsoft Phi-4 (14B Q4_K_M ~9.1GB) & Start Systemd Service
mkdir -p ~/models && cd ~/models
curl -L -o phi-4-Q4_K_M.gguf "https://huggingface.co/bartowski/phi-4-GGUF/resolve/main/phi-4-Q4_K_M.gguf"

sudo tee /etc/systemd/system/llama-server.service << 'EOF'
[Unit]
Description=llama.cpp API Server (Vulkan 40CU - Phi-4 14B)
After=network.target tailscaled.service

[Service]
Type=simple
User=bc250
WorkingDirectory=/home/bc250
ExecStart=/usr/local/bin/llama-server -m /home/bc250/models/phi-4-Q4_K_M.gguf --host 0.0.0.0 --port 8080 -ngl 99 -t 16 -c 8192
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload && sudo systemctl enable --now llama-server
